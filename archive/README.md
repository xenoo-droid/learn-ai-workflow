# Arsip

Folder ini hanya untuk **riwayat**. Isinya bukan aturan aktif dan **tidak diunggah ke ChatGPT Project**. Jika isinya bertentangan dengan `system/` atau `state/`, yang berlaku adalah `system/` dan `state/`.

| Lokasi | Isi |
|---|---|
| `progres-lama/` | Catatan progres tulisan tangan sebelum `state.yaml` (save lama, checkpoint 2026-08-17, achievements, catatan rilis kosong). Termasuk Level dan XP lama, yang belum punya aturan hitung dan akan dirancang ulang |
| `roadmap-v1.md` | Roadmap versi pertama, digantikan Roadmap v2 |
| `evaluasi/` | Evaluasi dan audit sistem belajar sebelum reboot |

Isi `archive/evaluasi/` hanya catatan proses belajar. Jika tidak ingin dipublikasikan, folder itu boleh dihapus tanpa memengaruhi sistem.
