# Sumber Belajar

Bacaan pendukung, disusun per World mengikuti Roadmap v2 (`system/02_roadmap.md`).

Aturan pakainya mengikuti `system/06_kebijakan_referensi.md`:

- **Dokumentasi resmi adalah sumber utama** materi. Tabelnya ada di `system/06_kebijakan_referensi.md`; yang di bawah hanya melengkapi.
- Daftar ini berisi sumber yang **direkomendasikan**, bukan sumber yang pasti dipakai di sesi tertentu. Sumber yang benar-benar dipakai dicatat mentor di bagian "Sumber yang dipakai" pada setiap sesi.
- Label: **[Resmi]** dokumentasi resmi, **[Gratis]**, **[Berbayar]**, **[ID]** berbahasa Indonesia.

Tautan yang ditambahkan pada 2026-10-30 sudah dicek keberadaannya pada tanggal itu. Tautan lain dibawa dari versi sebelumnya dan belum dicek ulang.

## 🌍 World 1 — Python Foundation

- **[Resmi]** The Python Tutorial (docs.python.org/3/tutorial/)
- **[Gratis]** Kaggle Learn (kaggle.com/learn): kursus Python singkat, langsung praktik di browser
- **[Gratis]** freeCodeCamp (freecodecamp.org): kursus Python lengkap dan banyak proyek
- **[Gratis][ID]** Kelas Terbuka (YouTube): pemrograman dalam Bahasa Indonesia

## 🌍 World 2 — Data Science & Data Analytics

### NumPy, Pandas, Matplotlib, Seaborn
- **[Resmi]** Dokumentasi NumPy, pandas, Matplotlib, dan seaborn: lihat tabel di `system/06_kebijakan_referensi.md`
- **[Resmi]** [pandas User Guide](https://pandas.pydata.org/docs/user_guide/index.html) (dicek 2026-10-30)
- **[Gratis]** Kaggle Learn: Pandas, Data Cleaning, Data Visualization
- **[Gratis]** Corey Schafer (YouTube): tutorial Pandas

### Jupyter / Google Colab
- **[Resmi]** [Project Jupyter Documentation](https://docs.jupyter.org/en/latest/) (dicek 2026-10-30)

### SQL & Database
- **[Resmi]** [PostgreSQL Tutorial (Part I)](https://www.postgresql.org/docs/current/tutorial.html) (dicek 2026-10-30)
- **[Gratis]** [SQLBolt](https://sqlbolt.com/): latihan SQL interaktif dari SELECT sampai JOIN (dicek 2026-10-30)

### Statistika Terapan
- **[Resmi]** [SciPy — Statistical functions (`scipy.stats`)](https://docs.scipy.org/doc/scipy/reference/stats.html): `ttest_ind`, `chi2_contingency`, dan lainnya (dicek 2026-10-30)
- **[Gratis]** StatQuest with Josh Starmer (YouTube): statistik dijelaskan pelan dan jelas
- **[Gratis]** Khan Academy (khanacademy.org): dasar statistik dan peluang

### Data Storytelling
- **[Resmi]** [Matplotlib — Annotations](https://matplotlib.org/stable/users/explain/text/annotations.html): `annotate`, teks, dan panah pada grafik (dicek 2026-10-30)
- **[Gratis/Berbayar]** [storytelling with data](https://www.storytellingwithdata.com/) (Cole Nussbaumer Knaflic): blog gratis; bukunya berbayar (dicek 2026-10-30)

### Kursus berbahasa Indonesia
- **[Gratis/Berbayar][ID]** DQLab (dqlab.id): modul pengantar gratis; kursus lanjutan dan sertifikat berbayar
