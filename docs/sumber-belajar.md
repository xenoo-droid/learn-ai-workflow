# Sumber Belajar AI dari Nol

Disusun mengikuti roadmap otodidak: Python → Numpy/Pandas → Math/Stats → ML Klasik → Deep Learning → GenAI/LLM

## Python & Fondasi Programming
- **[Gratis]** Kaggle Learn (kaggle.com/learn) — micro-course gratis, langsung praktik di browser
- **[Gratis]** freeCodeCamp (freecodecamp.org) — kursus Python lengkap + banyak project

## Data Tools (Numpy/Pandas)
- **[Gratis]** Kaggle Learn — course Pandas & Data Cleaning
- **[Gratis]** Corey Schafer (YouTube) — tutorial Pandas

## Matematika/Statistik untuk AI
- **[Gratis]** 3Blue1Brown (YouTube) — seri "Essence of Linear Algebra" & Neural Networks, penjelasan visual
- **[Gratis]** StatQuest with Josh Starmer (YouTube) — statistik dijelaskan pelan dan jelas
- **[Gratis]** Khan Academy (khanacademy.org) — dasar matematika/statistik

## Machine Learning Klasik
- **[Gratis]** Kaggle Learn — Intro to Machine Learning & Intermediate Machine Learning
- **[Gratis/Berbayar]** Coursera — Machine Learning Specialization (Andrew Ng): audit materi gratis, sertifikat & akses penuh berbayar
- **[Gratis]** Google Machine Learning Crash Course (developers.google.com/machine-learning)
- **[Gratis]** YouTube: Krish Naik, codebasics, sentdex

## Deep Learning
- **[Gratis]** Andrej Karpathy — "Neural Networks: Zero to Hero" (karpathy.ai/zero-to-hero.html): bangun neural network sampai GPT from scratch pakai Python
- **[Gratis]** fast.ai — "Practical Deep Learning for Coders": top-down, langsung bikin model di lesson pertama

## Generative AI / LLM (RAG, Agents, LangChain)
- **[Gratis]** Hugging Face NLP Course, LLM Course, & Agents Course (huggingface.co/learn) — termasuk sertifikat
- **[Gratis]** DeepLearning.AI Short Courses (deeplearning.ai) — banyak kursus singkat soal LangChain, RAG, agents
- **[Gratis]** Microsoft "Generative AI for Beginners" & "AI Agents for Beginners" — modul open-source, cari di GitHub
- **[Gratis]** Dokumentasi resmi LangChain (python.langchain.com)

## Peta Navigasi
- **[Gratis]** roadmap.sh/ai-data-scientist — roadmap komunitas untuk cross-check roadmap sendiri

## Sumber Berbahasa Indonesia
- **[Gratis]** DQLab (dqlab.id) — modul intro gratis pakai Python/R; **[Berbayar]** course lanjutan & sertifikat
- **[Gratis]** Kelas Terbuka (YouTube, dosen ITB) — programming & AI dalam Bahasa Indonesia
