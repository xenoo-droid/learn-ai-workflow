# Usulan Materi untuk Sistem Advanced Data Analyst

Dicatat 2026-10-30. Saat meninjau Roadmap v2, Rafa memutuskan bahwa **statistika terapan** dan **data storytelling** masuk Roadmap v2 (World 2, sebelum Portfolio #1). Materi di bawah ini **tidak** dimasukkan ke Roadmap v2. Materi ini disimpan sebagai bahan untuk sistem belajar kedua (kurikulum Advanced Data Analyst).

Dokumen ini bukan bagian roadmap atau kurikulum, dan tidak memengaruhi `state/state.yaml`.

| Usulan | Kenapa relevan untuk Data Analyst | Yang sudah ada di Roadmap v2 |
|---|---|---|
| **BI tools** (Power BI, Looker Studio, atau Tableau): model data, measure, dashboard interaktif, publikasi | Banyak lowongan Data Analyst meminta salah satu BI tool | Belum ada; Portfolio #1 hanya menyebut "laporan/dashboard sederhana" |
| **Excel / Google Sheets lanjutan**: pivot table, XLOOKUP/INDEX-MATCH, Power Query, conditional formatting | Masih menjadi alat harian di banyak tim bisnis | Belum ada |
| **Streamlit untuk dashboard analitik** lebih awal | Cara cepat membagikan analisis interaktif tanpa BI tool | Ada di World 6 (`dep_streamlit`) dalam konteks deployment aplikasi AI |
| **Git kolaboratif**: branch, pull request, code review, konflik merge | Kerja tim di repo analitik | Dasar Git ada di `python_mini_project`; alur Git ada di `se_testing_logging` (World 4) |

Celah lain yang masih tercatat di akhir `system/09_kurikulum.md` (window functions/CTE SQL, time series Pandas) tetap berstatus usulan untuk Roadmap v2 dan menunggu keputusan Rafa.
