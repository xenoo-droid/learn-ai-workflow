# 🧩 src

Folder ini berisi source code utama untuk aplikasi, tools, dan komponen yang akan dibangun di atas repository ini.

## Tujuan

Gunakan folder ini untuk kode yang memang dipakai sebagai bagian dari aplikasi atau automation, bukan catatan belajar biasa.

## Isi yang cocok

- Modul Python
- Utility functions
- Dashboard Streamlit
- Script automation
- Komponen AI workflow

## Aturan

- Simpan kode yang reusable di sini.
- Pisahkan logika dari notebook jika sudah menjadi aplikasi.
- Jaga struktur file tetap rapi dan konsisten.
- Buat subfolder jika project mulai membesar.
