# Learn A.I Workflow for Data Science — Roadmap v2 (SSOT)

> **Target:** Become a strong Data Professional who uses AI as a force multiplier.

## Priority Order
1. Data Science
2. Data Analytics
3. AI Literacy
4. Practical AI Automation
5. Software Engineering secukupnya
6. AI Engineering at foundation/application level

---

# WORLD 1 — Python Foundation
Python fundamentals, data structures, functions, modules, error handling, File I/O, virtual environments/pip, OOP basics, and light software-engineering exposure.

Project: Python Mini Project.

# WORLD 2 — Data Science & Data Analytics

## NumPy
Arrays, indexing/slicing, reshape, broadcasting, vectorization, statistics, sorting/searching, aggregation, linear algebra basics, random, file I/O, performance basics, capstone.

## Pandas
Fundamentals, selection, filtering, manipulation, missing values, sorting, statistics, grouping/combining, import/export, capstone.

Statistical visualization, distribution plots, categorical plots, relationship plots, heatmap, pairplot.

Notebook workflow, Markdown, reproducibility, kernel/runtime basics.

### Web Scraping (Optional)
requests, BeautifulSoup, simple dataset retrieval.

## SQL & Database Fundamentals
SELECT, WHERE, ORDER BY, GROUP BY, aggregation, JOIN, basic subqueries, relational concepts, SQLite, PostgreSQL fundamentals.

## AI untuk Pekerjaan Data — Familiarity Level
AI-assisted Python/SQL, debugging, EDA, data cleaning, visualization, documentation, and draft insights. Human validation remains mandatory.

### Portfolio Project #1
Data Analysis Report:
Dataset → Cleaning → EDA → Visualization → Insight → Report/Dashboard

# WORLD 3 — Mathematics & Statistics for Data/AI
Linear algebra, calculus, statistics, probability, optimization, and AI literacy. Portfolio: exploration notebooks.

# WORLD 4 — Machine Learning Fundamental
ML fundamentals, supervised/unsupervised learning, evaluation, scikit-learn, and formal practical software engineering.
Portfolio Project #2: Prediction / Classification Model.

# WORLD 5 — Deep Learning & Neural Network
Neural networks, deep learning concepts, one primary framework, and a classifier project.
Not focused on advanced infrastructure or training foundation models from scratch.

# WORLD 6 — Generative AI & AI-Enhanced Data Workflow
Generative AI fundamentals, prompt/context engineering, LLM APIs, RAG, workflow vs agents, automation, evaluation, guardrails/HITL, observability, MCP familiarity, and practical deployment.

## Capstone
AI-Enhanced Data Workflow demonstrating how AI improves real data work.

---

## Portfolio Progression
Data Analysis → Mathematics/Statistics → ML → Deep Learning → RAG → AI-Enhanced Data Workflow → Capstone

## Software Engineering Layer
Software engineering is transversal, not a separate career track:
- World 1: exposure
- World 2: practical reproducibility/repository habits
- World 3: basic testing and reproducible notebooks
- World 4: formal practical project structure
- World 5: maintainable ML/DL projects
- World 6: practical AI services/deployment

## Roadmap Change Rule
New topics are not added merely because they are trendy. Evaluate career relevance, data foundations, AI literacy, practical leverage, automation value, and required engineering depth. Changes require user approval.
