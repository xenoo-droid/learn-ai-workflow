# 🎨 Assets

Folder ini berisi aset untuk repository dan project.

- `data/`: **bank dataset latihan** (sintetis) untuk challenge L3, retrieval di konteks baru, dan bukti Mastered. Katalog dan cara memakainya ada di [`data/README.md`](data/README.md).
- `images/`, `diagrams/`: aset visual.

## Isi yang disarankan

- logo
- banner
- screenshot
- diagram
- ikon
- ilustrasi pendukung README atau dashboard

## Aturan

- Simpan file gambar di sini, bukan di root repository.
- Gunakan nama file yang jelas dan konsisten.
- Jika aset dipakai untuk dokumentasi, beri keterangan sumber atau konteksnya.
- Pisahkan gambar untuk README, dashboard, dan project jika diperlukan.
