# Evaluasi Roadmap — Learn A.I Workflow for Data Science

## 1. Tujuan Karier yang Diperjelas

Target utama proyek ini adalah:

> **Mendapatkan pekerjaan sebagai Data Scientist atau Data Analyst, dengan AI sebagai pilar penting dan nilai jual utama.**

AI tidak harus menjadi spesialisasi utama sampai level AI Engineer penuh. Target yang lebih tepat adalah menjadi **AI-native Data Professional**: memiliki fondasi Data Science/Data Analytics yang kuat dan mampu memanfaatkan AI untuk mempercepat, meningkatkan, dan mengotomatisasi pekerjaan data.

Prinsip utamanya:

> **AI sebagai force multiplier, bukan pengganti fondasi Data.**

---

## 2. Evaluasi Roadmap Awal

Roadmap enam fase yang sudah ada secara umum dinilai baik:

```text
Python
   ↓
Data Science
   ↓
Math & Statistics
   ↓
Machine Learning
   ↓
Deep Learning
   ↓
Generative AI & AI Workflow
```

Struktur tersebut tetap relevan karena membangun fondasi dari Python dan Data Science menuju ML/DL lalu GenAI.

### Penilaian umum

- Python Foundation: kuat
- Data Science: kuat
- Mathematics & Statistics: cukup kuat
- Machine Learning: cukup kuat
- Deep Learning: cukup proporsional
- Generative AI: relevan
- AI Workflow/Agent: perlu disesuaikan kedalamannya dengan target karier

**Kesimpulan:** roadmap tidak perlu dibuang atau diganti total. Yang perlu diperbaiki adalah kedalaman dan prioritas skill AI/engineering agar tidak menggeser fokus utama dari Data Science/Data Analytics.

---

## 3. Gap yang Ditemukan Saat Audit

Dalam evaluasi awal, ditemukan beberapa area yang secara teknis relevan untuk AI Engineering:

### Software Engineering
Diperlukan untuk membangun project yang lebih rapi dan reproducible.

### SQL & Database
Penting untuk pekerjaan Data Analyst/Data Scientist dan relevan untuk AI workflow.

### AI Evaluation
Penting untuk memastikan output AI/agent benar-benar dapat dipercaya.

### Guardrails & Human-in-the-loop
Relevan ketika AI mulai melakukan tindakan atau automation.

### Observability
Penting untuk memahami error, tool calls, latency, cost, dan perilaku sistem AI.

### Context Engineering
Mencakup pemilihan context, memory, state, retrieval context, dan tool results.

### MCP
Relevan untuk menghubungkan AI dengan tools, data, dan workflow eksternal.

### Workflow vs Agent Architecture
Penting untuk memahami bahwa tidak semua masalah membutuhkan agent. Workflow deterministik sering lebih tepat daripada agent yang kompleks.

## 5. Posisi Software Engineering

Software Engineering tetap penting, tetapi kedalamannya disesuaikan dengan target Data Science/Data Analyst.

### Penempatan yang direkomendasikan

| Fase | Kedalaman |
|---|---|
| Fase 1 — Python Foundation | Fondasi ringan: function, modular code, OOP dasar |
| Fase 2 — Data Science | Praktik: Git/GitHub, virtual environment, project structure |
| Fase 3 — Math & Statistics | Testing dasar, clean code, reproducibility |
| Fase 4 — Machine Learning | **Mulai lebih serius**: struktur project ML, modular code, testing, configuration |
| Fase 5 — Deep Learning | Lanjut secara praktis: architecture, config, logging |
| Fase 6 — GenAI & AI Workflow | Cukup untuk API, services, AI workflow, deployment dasar |

Jika harus memilih satu fase sebagai titik formal Software Engineering:

> **Fase 4 — Machine Learning Fundamental.**

Namun praktik fondasinya sudah dimulai sejak fase sebelumnya melalui Git/GitHub, environment, repository structure, dan clean code.

## 12. Kesimpulan Mentor

Roadmap terbaik untuk tujuan ini bukan roadmap yang paling panjang atau paling teknis.

Roadmap terbaik adalah roadmap yang membuat pengguna:

- kuat sebagai Data Scientist/Data Analyst;
- sangat familiar dengan AI;
- mampu menggunakan AI untuk coding, analysis, research, reporting, dan problem solving;
- mampu membuat automation sederhana yang berguna;
- memahami RAG dan agent tanpa harus menjadi specialist;
- memiliki software engineering yang cukup untuk membuat project yang rapi;
- tetap memiliki opsi untuk memperdalam AI Engineering di masa depan.

### Target akhir

> **Become a strong Data Professional who uses AI as a force multiplier.**
