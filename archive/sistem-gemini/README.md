# Gemini Notebook Source Pack

This package is a portable starting point for replicating the **system** of Learn A.I Workflow for Data Science while preserving the learner's existing progress.

## Recommended load order
1. Project Constitution
2. Roadmap SSOT
3. Current Progress State
4. Learning Evidence Log
5. Learning & Mentor Protocol
6. Gamification & Dashboard Specification

## Important
Do not treat the archive/history as equal authority to the active standards. The current progress state and roadmap are the operational references; evidence explains and supports state changes.
