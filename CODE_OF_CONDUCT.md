# Code of Conduct

## Our Pledge

We are committed to keeping this repository respectful, helpful, and focused on learning.

## Expected behavior

- Be constructive and clear.
- Keep feedback specific and actionable.
- Respect learning progress and agreed roadmap structure.
- Separate discussion, documentation, and implementation when possible.

## Unacceptable behavior

- Harassment or disrespect.
- Deliberate confusion or sabotage.
- Unrelated changes that break the learning workflow.
- Ignoring agreed repository standards.

## Enforcement

If a contribution does not fit these rules, it should be revised before merging.
