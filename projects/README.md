# 📂 Projects

Folder ini berisi seluruh project yang dibuat selama perjalanan belajar AI Workflow.

## Tujuan

Setiap project di folder ini adalah bukti praktik dari roadmap belajar. Project dipakai untuk mengubah teori menjadi hasil yang bisa dilihat, dijalankan, dan dipresentasikan.

## Struktur yang disarankan

```text
project-name/
├── README.md
├── notebook.ipynb
├── data/
├── src/
└── output/
```

## Aturan

- Satu folder untuk satu project.
- Wajib memiliki `README.md`.
- Jelaskan tujuan, dataset, cara menjalankan, hasil, dan lesson learned.
- Simpan file mentah dan output terpisah.
- Nama folder harus singkat dan jelas.
