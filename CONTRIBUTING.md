# Contributing Guidelines

Thanks for helping improve this repository.

## How to contribute

1. Keep changes small and focused.
2. Make sure every commit represents one clear improvement.
3. Update documentation when behavior or structure changes.
4. Keep the repository aligned with the learning roadmap.

## Suggested workflow

- Open an issue or describe the change clearly.
- Make the change in a separate branch when possible.
- Verify the result before pushing.
- Keep commit messages short and specific.

## Good commit examples

- `docs: update roadmap`
- `feat: add progress tracker`
- `chore: clean repository structure`

## What to avoid

- Unrelated changes in the same commit.
- Leaving broken files behind.
- Changing the roadmap structure without agreement.
